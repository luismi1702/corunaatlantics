# Tridente 3D Hero Background — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reemplazar el fondo de vídeo del hero con un tridente 3D sólido teal con aura dorada girando lentamente, construido con Three.js vía CDN.

**Architecture:** Se modifica únicamente `index.html`. El bloque `<div class="ocean-bg">` se reemplaza por un `<canvas id="trident-canvas">` + un div overlay. Three.js se carga con `importmap` desde CDN (sin npm, sin build). El script del tridente es un `<script type="module">` al final del `<body>`.

**Tech Stack:** Vanilla JS · Three.js r163 (CDN) · HTML5 Canvas · CSS3

## Task 2: Construir la geometría del tridente

**Files:**
- Modify: `index.html` — reemplazar el script de verificación por el tridente completo

- [ ] **Step 1: Reemplazar el script temporal por el script del tridente**

Eliminar el `<script type="module">` del Task 1 Step 5 y sustituirlo por:

```html
  <script type="module">
    import * as THREE from 'three';

    // ── RENDERER ──────────────────────────────────────────
    const canvas = document.getElementById('trident-canvas');
    const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
    renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
    renderer.setSize(window.innerWidth, window.innerHeight);
    renderer.setClearColor(0x040d12);

    // ── SCENE & CAMERA ────────────────────────────────────
    const scene = new THREE.Scene();
    const camera = new THREE.PerspectiveCamera(
      45,
      window.innerWidth / window.innerHeight,
      0.1, 100
    );
    camera.position.z = 11;

    // ── MATERIAL ──────────────────────────────────────────
    const mat = new THREE.MeshStandardMaterial({
      color:     0x4ECDC8,
      emissive:  0x0d3d3b,
      roughness: 0.25,
      metalness: 0.75,
    });

    // ── HELPERS ───────────────────────────────────────────
    function mkMesh(geo, x, y, z) {
      const m = new THREE.Mesh(geo, mat);
      m.position.set(x ?? 0, y ?? 0, z ?? 0);
      return m;
    }

    function addProng(x, bodyH, tipR, tipH, baseY) {
      const g = new THREE.Group();
      g.add(mkMesh(new THREE.CylinderGeometry(0.05, 0.05, bodyH, 8), 0, bodyH / 2, 0));
      g.add(mkMesh(new THREE.ConeGeometry(tipR, tipH, 8),             0, bodyH + tipH / 2, 0));
      g.position.set(x, baseY, 0);
      return g;
    }

    // ── TRIDENT ───────────────────────────────────────────
    const trident = new THREE.Group();

    // Mango (handle)
    trident.add(mkMesh(new THREE.CylinderGeometry(0.065, 0.09, 4.0, 16), 0, -1.5, 0));

    // Barra horizontal en la base de las púas
    const bar = mkMesh(new THREE.CylinderGeometry(0.04, 0.04, 1.1, 8), 0, 0.65, 0);
    bar.rotation.z = Math.PI / 2;
    trident.add(bar);

    // Púa central (más alta)
    trident.add(addProng(0,     1.8, 0.12, 0.5, 0.65));
    // Púa izquierda
    trident.add(addProng(-0.5,  1.3, 0.10, 0.4, 0.65));
    // Púa derecha
    trident.add(addProng( 0.5,  1.3, 0.10, 0.4, 0.65));

    scene.add(trident);

    // ── LIGHTS (temporales para verificar geometría) ──────
    scene.add(new THREE.AmbientLight(0xffffff, 1.0));

    // ── RENDER ESTÁTICO ───────────────────────────────────
    renderer.render(scene, camera);
  </script>
```

Sustituir por:
```js
    // ── LIGHTS ────────────────────────────────────────────
    scene.add(new THREE.AmbientLight(0xffffff, 0.15));

    // Luz dorada que orbita alrededor del tridente
    const goldLight = new THREE.PointLight(0xD4A843, 5, 25);
    scene.add(goldLight);

    // Luz teal de relleno desde abajo
    const tealFill = new THREE.PointLight(0x4ECDC8, 1.5, 20);
    tealFill.position.set(0, -4, 3);
    scene.add(tealFill);

    // ── ANIMATION LOOP ────────────────────────────────────
    const clock = new THREE.Clock();

    (function loop() {
      requestAnimationFrame(loop);
      const t = clock.getElapsedTime();

      trident.rotation.y = t * 0.18;                      // vuelta completa ~35s
      trident.position.y = Math.sin(t * 0.9) * 0.2;       // flotación ~7s ciclo

      goldLight.position.set(                              // luz orbita en círculo
        Math.cos(t * 0.18) * 5,
        2,
        Math.sin(t * 0.18) * 5
      );

      renderer.render(scene, camera);
    })();

    // ── RESIZE ────────────────────────────────────────────
    window.addEventListener('resize', () => {
      camera.aspect = window.innerWidth / window.innerHeight;
      camera.updateProjectionMatrix();
      renderer.setSize(window.innerWidth, window.innerHeight);
    });
```
